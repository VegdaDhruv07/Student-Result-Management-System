# 🎓 Student Result Management System

A simple console-based Student Result Management System developed using Python.

## 📌 Features

- ➕ Add Student
- 📋 View All Students
- 🔍 Search Student
- 🗑️ Delete Student
- 📊 Calculate Total Marks
- 📈 Calculate Percentage
- 🏆 Calculate Grade
- ✅ Show Pass/Fail Status
- 💾 Save Student Data using JSON
- 🔄 Load Saved Data when the program starts
- ✔️ Marks validation between 0 and 100

## 🛠️ Technologies Used

- Python
- JSON
- File Handling
